STYLEHUB - FASHION & APPAREL

Features:
- Fashion landing page
- Product listing
- Category section
- Session-based shopping cart
- Checkout form
- Simple order confirmation
- Responsive design

HOW TO RUN WITH XAMPP:
1. Extract this folder into C:\xampp\htdocs\
2. Start Apache from XAMPP Control Panel.
3. Open browser and visit:
   http://localhost/StyleHub-Fashion-Apparel/
4. Click Shop Now and add products to the cart.
5. Open Cart and proceed to checkout.

NOTE:
This is a student/demo project. Payment options are UI-only; no real payment gateway is connected.
